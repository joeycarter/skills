# Canadian spelling reference

Canadian English keeps British word endings but takes American `-ize`/`-yze` and
several individual American forms. When two forms are both current (listed below
as "either"), pick one and apply it consistently across the document set.

Authority: Writing Tips Plus and *The Canadian Style*; the tie-breaking
dictionary is the *Canadian Oxford Dictionary*, which lists the preferred
Canadian form first.

## 1. `-our` endings

armour, behaviour, candour, clamour, colour, demeanour, endeavour, favour,
fervour, flavour, harbour, honour, humour, labour, neighbour, odour, parlour,
rancour, rigour, rumour, saviour, splendour, valour, vapour, vigour

Derivatives that **keep** the `u`: colourful, colouring, colourless, favourable,
favourite, honourable, humourless, labourer, neighbourhood, rigourous *(no —
see below)*, behavioural.

Derivatives that **drop** the `u` — memorize these, they are the usual error:

| Base | Derivative |
|---|---|
| colour | coloration, colorimetric |
| honour | honorary, honorific, honorarium |
| humour | humorous, humorist |
| labour | laborious, collaborate, elaborate |
| odour | odorous, deodorant |
| rigour | rigorous |
| vapour | vaporize, vaporous, evaporate |
| vigour | vigorous, invigorate |

`Labour Day` is the Canadian holiday. `Labour` is the party in the UK; `Labor` in
Australia. Department names are fixed: *Employment and Social Development Canada*.

## 2. `-re` endings

calibre, centre, fibre, litre, lustre, manoeuvre (or *maneuver*), metre, mitre,
ochre, sabre, sceptre, sombre, spectre, theatre, titre

`-er` stays for devices and instruments: parking meter, water meter, voltmeter,
flow meter, speedometer, barometer, perimeter, diameter, thermometer.
Distinguish **metre** (the SI unit of length) from **meter** (a measuring
device).

Derivatives: central, centric, centrifugal, fibrous, theatrical, metric — all
`-er`-less and unaffected.

## 3. `-ce` noun / `-se` verb

| Noun | Verb |
|---|---|
| advice | advise |
| device | devise |
| licence | license |
| practice | practise |
| prophecy | prophesy |

Also nouns with `c`: defence, offence, pretence. Their adjectives take `s`:
defensive, offensive. "A licensed practitioner practises under a licence."

Note the software-world collision: the **`license` field in `package.json`**,
the file `LICENSE`, and the SPDX identifier are literal strings — never change
them. Prose about the document can say *licence*, but match the repository's
existing usage if it already standardized on *license*.

## 4. `-ize` and `-yze` (American pattern, Canadian standard)

analyze, apologize, authorize, catalyze, categorize, characterize, civilize,
criticize, customize, emphasize, equalize, finalize, generalize, hypothesize,
initialize, itemize, legalize, localize, maximize, memorize, minimize,
modernize, normalize, optimize, organize, paralyze, prioritize, randomize,
realize, recognize, sanitize, serialize, specialize, standardize, summarize,
synchronize, synthesize, utilize (prefer *use*), virtualize, visualize

Nouns follow: organization, authorization, standardization, analysis.

Words that are **never** `-ize` regardless of dialect: advertise, advise,
comprise, compromise, devise, exercise, improvise, revise, supervise, surmise,
surprise, televise.

## 5. Doubled consonant before a suffix

Canadian English doubles a final `l` after a short vowel regardless of stress.

cancelled, cancelling (but **cancellation** in every dialect), channelled,
counsellor, dialled, dishevelled, enrolled, enrolling, equalled, fuelled,
fuelling, funnelled, initialled, jeweller, jewellery, labelled, labelling,
levelled, marvellous, modelled, modelling, panelled, quarrelling, signalled,
signalling, totalled, travelled, travelling, traveller, tunnelled

Also: kidnapped, programmer, programming, worshipped, benefited (single `t`),
focused (single `s` preferred; *focussed* is acceptable).

Single `l` where the root ends in one: fulfil, instal (prefer **install**),
enrol, skilful, wilful, distil, instil, appal, annul.

| fulfil, fulfilment | fulfill, fulfillment (either is defensible; be consistent) |

## 7. American forms Canadian English keeps

program (not *programme*), tire (not *tyre*), curb (not *kerb*), aluminum (not
*aluminium*), jail (not *gaol*), specialty (not *speciality*), airplane (not
*aeroplane*), inquiry (preferred to *enquiry*), among (not *amongst*), while (not
*whilst*), toward (no trailing `s`), math (not *maths*), fall (as well as
*autumn*).

Scientific spellings follow international usage: sulfur, fetus, estrogen,
aluminum.

## 8. `-ogue`/`-og`, `-ae`/`-oe`, `-ment`

- Drop the classical digraph: encyclopedia, medieval, fetus, anesthesia,
  diarrhea, esophagus. Keep it in proper nouns and taxonomy.
- judgment is standard in legal contexts; judgement is acceptable elsewhere.
  Use **judgment** in technical documentation for consistency.
- acknowledgment / acknowledgement — either; prefer **acknowledgment**.

## 9. Confusables worth checking in technical prose

| Word | Use |
|---|---|
| affect / effect | *affect* = verb, influence; *effect* = noun, result (or verb, bring about) |
| complement / compliment | *complement* = completes; *compliment* = praise |
| comprise / compose | the whole *comprises* the parts; the parts *compose* the whole |
| continual / continuous | *continual* = repeated; *continuous* = uninterrupted |
| dependant / dependent | *dependant* = a person (noun); *dependent* = adjective. The software term is **dependency**/**dependencies** |
| discreet / discrete | *discreet* = tactful; *discrete* = separate |
| ensure / insure / assure | *ensure* = make certain; *insure* = indemnify; *assure* = reassure a person |
| its / it's | possessive / contraction of *it is* |
| login / log in | noun or adjective / verb. Same for *setup*/*set up*, *backup*/*back up*, *logout*/*log out* |
| principal / principle | chief / a rule |
| stationary / stationery | not moving / paper |
| than / then | comparison / sequence |
| e.g. / i.e. | *for example* / *that is* — in plain-language prose, write the English out |

## 10. Compounds and hyphenation

- Hyphenate a compound modifier before a noun: *read-only file*, *third-party
  library*, *end-to-end test*, *well-documented API*. Do not hyphenate after the
  noun: *the file is read only*.
- No hyphen after an `-ly` adverb: *fully qualified domain name*, *highly
  available cluster*.
- Closed by convention: email, website, online, offline, filename, hostname,
  username, runtime, workflow, metadata, namespace, timestamp, lifecycle.
- Open by convention: command line (noun), data set, log file, build system,
  machine learning, open source (hyphenate as a modifier: *open-source licence*).
- Keep the hyphen in: re-enter, re-create (make again, vs *recreate*), co-worker,
  non-blocking, self-signed, multi-tenant (either; be consistent), pre-existing.
- `Métis` keeps its accent. French proper nouns keep theirs: *Montréal* in
  French-language and bilingual material, *Montreal* in English federal usage;
  the province is *Quebec* in English, *Québec* in French.
